1) PRODUCT GOAL
================================================================================
ReachInsta helps Instagram creators and agencies track competitors and discover viral Reels. Users can add up to N competitors (based on plan), fetch competitor Reels data for a selected time range (7/14/28 days), see dashboards and insights, and export CSV (Pro only). Data comes from Apify using TWO different actors:
- Actor A: “Instagram Scraper” → Reel-level metrics (username, reel url, views, likes, comments, video duration, reel upload timestamp)
- Actor B: “Instagram Followers Count Scraper” → username + followers count
We must merge both outputs into final datasets for analytics + display.

================================================================================
